# Databricks for Data Engineering

This module covers **Databricks from basic to advanced strictly from a Data Engineering perspective**.
The goal is to make this section **self-sufficient**, so no external resources are required
to understand or revise Databricks for Data Engineer roles.

## What this module covers
- Databricks workspace basics (clusters, notebooks, repos)
- Databricks File System (DBFS) and data storage concepts
- Delta Lake fundamentals (Delta tables, ACID, schema evolution)
- Databricks SQL (queries, views, dashboards)
- ETL pipelines using notebooks + jobs
- Incremental loads using MERGE (upserts)
- Medallion architecture (Bronze → Silver → Gold)
- Partitioning and performance optimization
- Data quality checks and validation workflows
- Interview-ready Databricks concepts for DE roles

## Folder Structure
- `00_resources` – Optional references (not mandatory)
- `01_notes` – Concept explanations (basic → advanced)
- `02_practicals` – Hands-on Databricks notebooks (SQL + PySpark)
- `03_projects` – Real-world Databricks Data Engineering projects
- `04_interview_questions` – Databricks interview questions for Data Engineers

## Outcome
After completing this module, you will be able to:
- Build end-to-end ETL pipelines in Databricks
- Work with Delta Lake tables in production style
- Implement incremental loads and medallion architecture
- Optimize Databricks jobs for large-scale data
- Confidently answer Databricks interview questions for Data Engineering roles
