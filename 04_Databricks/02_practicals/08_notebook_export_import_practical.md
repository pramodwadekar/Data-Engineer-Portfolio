# 08 - Notebook Export & Import Practical (Databricks)

🎯 Goal: Learn how to export notebooks and import them into another workspace.

---

## ✅ What you will learn
- Export notebook
- Import notebook
- Understand notebook formats (.py, .ipynb, .dbc)
- Best practice for version control

---

## 1) Export Notebook
Go to your notebook.

Click:
File → Export

You will see formats:
- Source file (.py)
- Jupyter (.ipynb)
- HTML
- DBC archive

---

## 2) Best Format for Git
Recommended:
✅ **Source file (.py)**

Why?
- clean diffs
- easy code review

---

## 3) Import Notebook
Workspace → right click folder → Import

Choose:
- `.py` or `.ipynb`

---

## 4) DBC Archive (Databricks Archive)
DBC is used for:
- sharing multiple notebooks
- exporting a whole folder

---

## 5) Practical Task
1) Export any notebook as `.py`
2) Import it into:
   `Workspace/Users/<email>/02_practicals/import_test/`
