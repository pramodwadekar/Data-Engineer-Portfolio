# 07 - Branch, Commit, Push Practical (Databricks)

🎯 Goal: Learn how to use Git workflow inside Databricks Repos.

---

## ✅ What you will learn
- Create branch
- Make changes
- Commit changes
- Push to GitHub
- Handle pull updates

---

## 1) Open Your Repo in Databricks
Left menu → Repos → open your repo

---

## 2) Create a Feature Branch
Top repo menu:
- Branch → Create branch

Example branch name:
```
feature/databricks-practicals
```

---

## 3) Make a Change
Edit a README or create a notebook file.

Example:
Create:
`/04_Databricks/02_practicals/test_git_commit.md`

Content:
```markdown
# Git Test
This file was committed from Databricks Repo.
```

---

## 4) Commit Changes
Go to:
Repos → Changes

Steps:
1. Select file
2. Add commit message:
   - `Added databricks repo commit test`
3. Click **Commit & Push**

---

## 5) Verify in GitHub
Open GitHub repo and check:
- file exists
- branch updated

---

## 6) Pull Latest Changes
If team changes happen:

Repos → Pull

---

## 7) Best Practices
- always use branches
- commit small changes
- pull before push
- avoid editing same notebook in multiple branches

---

## 8) Output
After this practical:
✅ you can create branch  
✅ commit and push changes from Databricks  
✅ understand basic Git flow
