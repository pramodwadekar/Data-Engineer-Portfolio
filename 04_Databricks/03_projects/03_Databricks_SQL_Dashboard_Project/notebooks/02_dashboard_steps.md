# Databricks SQL Dashboard Steps (Quick)

1) Compute → SQL Warehouse → Create (Small) + Auto stop
2) SQL → Query editor
3) Run:
   - sql/02_gold_kpis.sql
   - sql/03_dashboard_queries.sql
4) For each query:
   - Add visualization
   - Add to dashboard
5) Create Alerts:
   - use sql/04_alert_queries.sql

Tip:
Use gold tables only for dashboards.
