# 01 - Databricks Notes (Basic → Advanced)

- DBFS

- Delta Lake (platform side)
- Unity Catalog
- Jobs & Workflows
- Repos (Git integration)
- Secrets
- Auto Loader
- Delta Live Tables (DLT)
- Monitoring + Cost Optimization
- Best Practices + Interview Notes
- CI/CD + Asset Bundles (Bonus)
- Databricks REST API (Bonus)
- SQL Warehouses deep (Bonus)
- MLflow basics (Bonus)
