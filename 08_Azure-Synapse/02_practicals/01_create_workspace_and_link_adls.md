# 01 - Create Workspace and Link ADLS (Practical)

## Goal
Create Synapse workspace and connect ADLS Gen2.

## Steps
1. Create ADLS Gen2 account
2. Create container: `raw`, `curated`
3. Create Synapse workspace
4. Link ADLS as primary storage
5. Create linked service to ADLS

## Output
You should see storage in Synapse Studio Data hub.
