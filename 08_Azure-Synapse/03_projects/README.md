# 03_Projects — Azure Synapse (Interview Ready)

This folder contains **3 end-to-end Azure Synapse projects** designed for:
- Data Engineer roles
- Synapse Developer roles
- DP-203 interviews

## Why these projects are strong
Because they prove you can work with:
- ADLS Gen2
- Serverless SQL (OPENROWSET, External tables, CETAS)
- Dedicated SQL Pool (MPP, distribution, columnstore)
- Synapse Spark (Delta)
- Synapse Pipelines (full + incremental)
- Security (Managed Identity, Key Vault)
- Monitoring + cost optimization

## Projects Included
1. Lakehouse + Serverless + CETAS Gold Layer
2. Enterprise DWH on Dedicated SQL Pool (MPP)
3. Hybrid: Spark ETL + Dedicated Serving + Pipelines

---

## Interview Tip
Implement **Project 2 or 3 fully**.
Project 1 is fast and shows serverless cost optimization.
