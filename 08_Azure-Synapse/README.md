# 08 - Azure Synapse Analytics (Basic → Advanced)

This module covers **Azure Synapse Analytics** end-to-end for Data Engineers.

## What you will learn
- Synapse workspace architecture
- Serverless SQL vs Dedicated SQL pool
- External tables, OPENROWSET, CETAS
- Dedicated distribution (hash/round-robin/replicated)
- Columnstore, partitions, statistics
- Synapse Pipelines (ADF inside Synapse)
- Spark pools and notebooks
- Security: RBAC, Managed Identity, Private endpoints
- Monitoring, cost optimization
- Real interview scenarios
