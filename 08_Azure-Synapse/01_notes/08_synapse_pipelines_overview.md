# 08 - Synapse Pipelines (ADF inside Synapse)

Synapse Pipelines = ADF capabilities embedded.

## Common activities
- Copy activity
- Notebook activity (Spark)
- SQL script activity
- Execute pipeline
- If / ForEach / Until
- Get metadata, Lookup

## Use cases
- ingest data to ADLS
- orchestrate loads into dedicated pool
- run transformations in Spark
