# 03 - Synapse Workspace Components

## Synapse Studio
Web UI for:
- SQL scripts
- Notebooks
- Pipelines
- Monitoring
- Data browsing

## Linked Services
Connection definitions:
- ADLS
- SQL DB
- Cosmos DB
- Key Vault
- Power BI

## Integration runtime
Synapse has managed IR by default.
For on-prem sources, use self-hosted IR (via ADF).

## SQL pool
- Serverless: built-in
- Dedicated: provisioned

## Spark pool
Managed Apache Spark cluster.
