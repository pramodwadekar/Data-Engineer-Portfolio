# 09 - Spark Pools in Synapse

## Spark pool
Managed Apache Spark cluster.

Supports:
- PySpark
- Scala
- Spark SQL

## When to use Spark in Synapse
- heavy transformations
- ML workloads
- large file processing

## Compared to Databricks
Databricks is richer for:
- Delta Lake features
- job workflows
- Unity catalog

Synapse Spark is good for:
- integrated Microsoft ecosystem
- simple transformations
