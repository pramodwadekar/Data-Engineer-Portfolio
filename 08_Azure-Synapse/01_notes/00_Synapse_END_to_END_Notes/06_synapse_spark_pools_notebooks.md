# 06 — Synapse Spark Pools + Notebooks

## What is Synapse Spark?
Managed Spark clusters inside Synapse.

Used for:
- ETL
- Delta Lake
- Machine learning
- notebooks

---

## Spark pool concepts
- Node size (Small/Medium/Large)
- Autoscale
- Autopause
- Spark version
- Libraries

---

## Synapse Notebooks
Similar to Databricks notebooks.
Supports:
- PySpark
- Scala
- SQL

---

## Delta Lake support
Synapse Spark can read/write Delta tables in ADLS.

---

## Interview points
- Databricks Spark is more mature
- Synapse Spark is good for integrated analytics
