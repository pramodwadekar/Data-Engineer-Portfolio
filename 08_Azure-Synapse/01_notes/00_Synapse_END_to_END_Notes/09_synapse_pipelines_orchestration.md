# 09 — Synapse Pipelines (ADF inside Synapse)

## What are Synapse pipelines?
Synapse pipelines = Azure Data Factory features inside Synapse.

You can:
- copy activity
- data flows
- triggers
- parameters
- variables
- integration runtime

---

## Common pipeline patterns
1. Full load pipeline
2. Incremental load with watermark
3. ForEach loop for partitions
4. Metadata-driven pipelines

---

## Interview points
- Same concept as ADF
- Used when everything is inside Synapse workspace
