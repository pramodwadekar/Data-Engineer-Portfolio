# 11 - Monitoring and Cost Optimization

## Serverless cost
Pay per TB scanned.
Optimize by:
- use parquet
- partition folders by date
- select only needed columns

## Dedicated cost
Pay for provisioned DWU.
Optimize by:
- pause/resume
- scale up/down
- workload management

## Monitoring tools
- Synapse Monitor hub
- Dynamic management views (DMVs)
