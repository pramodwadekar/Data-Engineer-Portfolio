# 10 - Security in Synapse

## Identity options
- Managed Identity (recommended)
- Service principal
- SAS tokens (not recommended for prod)

## RBAC vs ACL
- RBAC: Azure role assignments
- ACL: file-level permissions on ADLS paths

## Networking
- Private endpoints
- Managed VNet

## Interview points
- Use Key Vault for secrets
- Prefer managed identity
- Use least privilege
