# 🚀 SQL Projects (Data Engineering)

This folder contains **end-to-end SQL projects** designed for **Data Engineer interviews**.

Each project is built in a real Data Engineering style:

✅ Raw ➝ Staging ➝ DWH (Fact + Dimension)  
✅ Data Cleaning (dirty data: nulls, duplicates, invalid values)  
✅ KPI / Analytics Queries  
✅ Data Quality Checks  
✅ Performance Optimization  
✅ PostgreSQL + Databricks SQL versions (Delta Lake + MERGE)
