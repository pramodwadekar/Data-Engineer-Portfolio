# SQL Functions

## 📖 Introduction
SQL provides a wide range of **built-in functions** to manipulate and process data. These functions act as pre-written blocks of code that execute specific tasks on our data.

Some commonly used categories of SQL functions include:
- Numeric functions
- Character functions
- Conversion functions
- Date functions
- Aggregate functions
- Miscellaneous functions

Functions are categorized into two types:
| Function Type     | Operates On       | Returns      | Used In Clauses                        |
|-------------------|------------------ |--------------|----------------------------------------|
| Single-row        | Single row        | Single value | SELECT, WHERE, ORDER BY, HAVING        |
| Multi-row         | Multiple rows     | Single value | SELECT, ORDER BY, HAVING               |
