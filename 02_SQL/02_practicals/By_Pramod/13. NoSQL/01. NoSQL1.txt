✅ SQL vs NoSQL Schema Illustration
SQL Table (Rigid Schema)
CREATE TABLE Users (
  FirstName VARCHAR(50),
  LastName VARCHAR(50),
  Email VARCHAR(100),
  Gender VARCHAR(10),
  Landline VARCHAR(15),
  Mobile VARCHAR(15)
);


NoSQL Document (Flexible Schema)
{
  "UserName": { "firstName": "James" },
  "Email": "james@abc.com",
  "Gender": "Male",
  "ContactNo": { "landLine": "123", "mobile": "456" }
}

{
  "UserName": { "firstName": "Ethan", "lastName": "McCarty" },
  "Email": "ethan@abc.com",
  "ContactNo": { "mobile": "789" }
}



📌 Key Insight:
- SQL → rigid schema, centralized, vertical scaling.
- NoSQL → flexible schema, distributed, horizontal scaling.
- Different NoSQL types (Key-Value, Column Family, Document, Graph) are suited for different workloads.
