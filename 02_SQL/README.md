# SQL for Data Engineering

This module covers **SQL from basic to advanced strictly from a Data Engineering perspective**.
The goal is to make this section **self-sufficient**, so no external resources are required
to understand or revise SQL for Data Engineer roles.

## What this module covers
- SQL fundamentals (SELECT, WHERE, GROUP BY, JOIN)
- Data cleaning and transformation using SQL
- Window functions
- CTEs, Subqueries, and advanced aggregations
- Data Quality checks (duplicates, nulls, orphan records)
- Performance tuning (indexes, query optimization)
- Interview-ready SQL concepts for DE roles

## Folder Structure
- `00_resources` – Optional references (not mandatory)
- `01_notes` – Concept explanations (basic → advanced)
- `02_practicals` – Hands-on SQL queries and practice sets
- `03_Projects` – Real-world SQL Data Engineering projects (PostgreSQL + Databricks SQL)
- `04_interview_questions` – SQL interview questions for Data Engineers

## Outcome
After completing this module, you will be able to:
- Write clean and optimized SQL queries
- Perform data cleaning and transformations in SQL
- Design analytics-ready Data Warehouse tables
- Build end-to-end SQL projects for interviews
- Confidently answer SQL interview questions for Data Engineering roles
