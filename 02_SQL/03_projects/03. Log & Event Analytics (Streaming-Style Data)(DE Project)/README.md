# 📊 Event & Log Analytics System - SQL Project

## 📌 Project Overview

This project simulates an **Event and Log Analytics system** similar to what is used in real-world applications (websites, mobile apps, backend systems).

It focuses on:
- Storing large volumes of event data
- Cleaning and validating data
- Performing time-based aggregations
- Generating usage and monitoring reports
- Optimizing queries using indexes and views

This is a **Data Engineering oriented SQL project** focused on analytics and data processing.

---

## 🧩 Why This Project?

In real companies, data engineers work with:
- Application logs
- User activity events
- System metrics
- Clickstream data

This project was built to:
- Practice **working with event-style data**
- Learn **time-based aggregations**
- Write **analytics queries for large tables**
- Perform **data quality checks**
- Build **monitoring and usage reports**

---

## 🏗️ What Is Built?

- Event tables (user events, system events)
- Data cleaning SQL scripts
- Aggregation tables / queries
- Views for daily and monthly analytics
- Indexes for performance
- Data quality checks
- Reports like:
  - Daily active users
  - Events per day
  - Most active users
  - Error events count
  - Peak usage hours

---

## 🎯 How to Explain This to an Interviewer

"I built an event analytics system using SQL where I store and analyze application event data.  
I wrote queries for data cleaning, time-based aggregations, and reporting like daily active users and peak usage hours.  
This project is similar to how log and event data is analyzed in real systems for monitoring and analytics."
