# 🏬 Retail Data Warehouse & Sales Analytics - SQL Project

## 📌 Project Overview

This project simulates a **Retail Data Warehouse** used for analytics and business reporting.  
It demonstrates how raw transactional data can be transformed into **analytics-ready tables** using SQL.

The project focuses on:
- Data modeling (Fact & Dimension tables)
- ETL-style transformations using SQL
- Data quality checks
- Performance optimization using indexes
- Business reporting queries

This is a **Data Engineering focused SQL project**, not just CRUD operations.

---

## 🧩 Why This Project?

In real companies, data engineers build systems that:
- Collect data from multiple sources
- Clean and transform data
- Store it in a data warehouse
- Make it ready for analytics and dashboards

This project was created to:
- Practice **data warehouse design**
- Learn **how to transform raw data into analytical data**
- Write **ETL logic using SQL**
- Generate **business insights from data**
- Build a **portfolio-level data engineering project**

---

## 🏗️ What Is Built?

- Source tables (raw transactional data)
- Dimension tables (Date, Customer, Product, Category)
- Fact table (Sales)
- ETL SQL scripts to load dimensions and facts
- Indexes for performance
- Views for reporting
- Data quality check queries
- Business reports like:
  - Daily / Monthly sales
  - Top products
  - Top customers
  - Revenue by category
