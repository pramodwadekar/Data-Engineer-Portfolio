# PySpark for Data Engineering

This module covers **PySpark from basic to advanced strictly from a Data Engineering perspective**.
The goal is to make this section **self-sufficient**, so no external resources are required
to understand or revise PySpark for Data Engineer roles.

## What this module covers
- Spark fundamentals (RDD vs DataFrame vs Dataset concepts)
- Reading and writing data (CSV, JSON, Parquet, Delta)
- Data transformation using PySpark DataFrames
- Spark SQL and DataFrame API
- Joins, aggregations, and window functions in PySpark
- Handling nulls, duplicates, and bad data (data cleaning)
- Partitioning, bucketing, and file optimization
- Performance tuning (shuffle, caching, broadcast joins)
- Building ETL pipelines using PySpark
- Interview-ready PySpark concepts for DE roles

## Folder Structure
- `00_resources` – Optional references (not mandatory)
- `01_notes` – Concept explanations (basic → advanced)
- `02_practicals` – Hands-on PySpark notebooks/scripts
- `03_projects` – Real-world PySpark Data Engineering projects
- `04_interview_questions` – PySpark interview questions for Data Engineers

## Outcome
After completing this module, you will be able to:
- Build scalable ETL pipelines using PySpark
- Transform and clean large datasets efficiently
- Optimize Spark jobs for performance
- Work with real-world Data Engineering workflows
- Confidently answer PySpark interview questions for Data Engineering roles
