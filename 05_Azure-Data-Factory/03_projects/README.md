# ADF - 3 Interview Ready Projects (Portfolio Pack)

This pack contains **3 Azure Data Factory projects** designed for Data Engineer interviews.

## Projects
1. Metadata Driven Watermark Framework (ADF + SQL + ADLS + Databricks)
2. Event Driven File Ingestion + Quarantine Pattern
3. ADF CI/CD Multi Environment Deployment (ARM Templates)

## How to use
- Upload folder `03_Azure_Data_Factory/03_projects/` in your GitHub repo
- Keep README for each project
- Add screenshots after building pipelines in ADF Studio
