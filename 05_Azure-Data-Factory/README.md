# Azure Data Factory (ADF) for Data Engineering

This module covers **Azure Data Factory from basic to advanced strictly from a Data Engineering perspective**.
The goal is to make this section **self-sufficient**, so no external resources are required
to understand or revise ADF for Data Engineer roles.

## What this module covers
- ADF fundamentals (pipelines, activities, datasets, linked services)
- Copy Activity (ingestion from multiple sources)
- Data Flow basics (mapping data flows)
- Parameterization and dynamic pipelines
- Triggers (schedule, tumbling window, event-based)
- Integration Runtime (Azure IR vs Self-hosted IR)
- Incremental load patterns (watermark, last modified date)
- Error handling and retry logic
- Monitoring, alerts, and pipeline debugging
- CI/CD basics using Git integration
- Interview-ready ADF concepts for DE roles

## Folder Structure
- `00_resources` – Optional references (not mandatory)
- `01_notes` – Concept explanations (basic → advanced)
- `02_practicals` – Hands-on ADF pipeline examples
- `03_projects` – Real-world ADF projects (end-to-end pipelines)
- `04_interview_questions` – ADF interview questions for Data Engineers

## Outcome
After completing this module, you will be able to:
- Build end-to-end ingestion pipelines using ADF
- Create dynamic and reusable pipelines with parameters
- Implement incremental loading and automation using triggers
- Monitor and troubleshoot production pipelines
- Confidently answer ADF interview questions for Data Engineering roles
