# 22 - Self-hosted Integration Runtime (On-Prem Simulation) (Practical)

## Goal
Understand Self-hosted IR setup (common in companies).

---

## When needed?
- on-prem SQL Server
- private network resources
- firewall restricted systems

---

## Steps (high level)
1. Create Self-hosted IR in ADF
2. Download IR installer
3. Install on VM
4. Register with key
5. Test connection

---

## Interview Points
- self-hosted IR is used for on-prem connectivity
