# 17 - ADF to Databricks (Job Cluster Best Practice) (Practical)

## Goal
Run Databricks notebook using Job Cluster pattern.

---

## Best practice
- Use Databricks Jobs for production
- ADF triggers the job
- Job uses job cluster (ephemeral)

---

## Why?
- cheaper
- isolated
- reproducible

---

## Interview Points
Say:
> “In prod we run notebooks via Jobs on job clusters.”
