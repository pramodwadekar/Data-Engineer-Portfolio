# 23 - CI/CD Deployment using ARM Templates (Practical)

## Goal
Deploy ADF from dev to prod using ARM templates.

---

## Steps
1. Develop in dev factory with Git
2. Publish
3. Export ARM template from publish branch
4. Deploy to prod factory using Azure DevOps pipeline

---

## Key point
Linked services must be parameterized (env-specific).

---

## Interview Points
- ADF uses ARM templates for CI/CD
- publish branch stores deployment artifacts
