# 12 - Mapping Data Flows (ADF) (Optional)

## 1) What is Mapping Data Flow?
A GUI-based transformation tool in ADF.
Runs on Spark clusters managed by ADF.

---

## 2) Data Flow vs Databricks
### Data Flow
- no-code transformations
- easier for small-medium transformations

### Databricks
- full Spark power
- best for complex transformations

---

## 3) When to use Data Flow?
- simple joins, derived columns
- basic aggregations
- when no Databricks is available

---

## 4) Common Interview Questions
### Q1: Data Flow runs on what?
Runs on Spark cluster created by ADF.

### Q2: Is Data Flow same as Databricks?
No, Databricks is more powerful.

---

## 5) Best Practices
- avoid heavy transformations in Data Flow
- use it only if business needs no-code
