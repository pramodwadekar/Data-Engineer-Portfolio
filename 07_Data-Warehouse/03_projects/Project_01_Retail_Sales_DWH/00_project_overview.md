# Project 01 — Retail Sales Data Warehouse (End-to-End)

## What is this project?
An end-to-end **Retail Sales Data Warehouse** built using **Kimball dimensional modeling**.

## Why this project matters?
Retail DWH is the most common use-case in:
- E-commerce companies
- FMCG companies
- Electronics retail chains
- Quick-commerce (Blinkit/Zepto)

Interviewers check whether you understand:
- Star schema
- Fact grain
- SCD2
- Incremental loads
- BI queries

## What you will deliver
- Star schema tables
- Incremental ETL
- SCD2 for customer/product
- DQ checks
- Data mart aggregations
