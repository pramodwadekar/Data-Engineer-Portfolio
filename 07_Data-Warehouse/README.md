# 07 - Data Warehouse (Basic → Advanced)

This module covers **Data Warehousing for Data Engineering** from **Basic → Advanced**.

## What you will learn
- OLTP vs OLAP
- Dimensional modeling (Star/Snowflake)
- Fact & Dimension tables
- Grain, surrogate keys, conformed dimensions
- SCD (Type 0/1/2/3/4/6)
- Incremental loads
- Partitioning, clustering, indexing
- Data quality, governance
- KPI/semantic layer
- Real interview system design questions

## Folder Structure
- `00_resources` – curated learning links
- `01_notes` – concepts (basic → advanced)
- `02_practicals` – hands-on SQL modeling tasks
- `03_projects` – 3 end-to-end DW projects
- `04_interview_questions` – interview Q&A
