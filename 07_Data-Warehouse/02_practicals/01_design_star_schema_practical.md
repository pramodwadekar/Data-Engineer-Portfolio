# 01 - Design Star Schema (Practical)

## Goal
Design a star schema for Retail Sales.

## Entities
- customers
- products
- stores
- orders

## Deliverables
- DimCustomer
- DimProduct
- DimStore
- DimDate
- FactSales

## Interview Explanation
Explain:
- grain: one row per order_line
- measures: sales_amount, quantity
- dimensions used for slicing
