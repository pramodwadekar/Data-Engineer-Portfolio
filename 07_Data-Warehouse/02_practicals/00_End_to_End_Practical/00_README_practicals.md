# 07_Data-Warehouse — Practicals (Basic → Advanced)

This folder contains **hands-on practicals** for Data Warehouse concepts.

## What you will build
A complete mini Data Warehouse using:
- Raw staging tables
- Dimension tables
- Fact tables
- SCD Type 1 and Type 2
- Incremental loading
- Data quality checks
- Performance optimization
- Star schema + data mart style queries

## Tools
You can do these practicals using any of the following:
- Databricks + Delta Lake (recommended)
- SQL Server / PostgreSQL
- Azure Synapse (Dedicated or Serverless)
- MySQL (works for basics)

## Dataset used (simple)
We will use a simple retail dataset:
- customers
- products
- stores
- orders
- order_items

You can generate sample data from the provided SQL.
