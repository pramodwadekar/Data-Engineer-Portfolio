# Python for Data Engineering

This module covers **Python from basic to advanced strictly from a Data Engineering perspective**.
The goal is to make this section **self-sufficient**, so no external resources are required
to understand or revise Python for DE roles.

## What this module covers
- File handling and data ingestion
- Data transformation using Pandas
- Exception handling and logging
- Config-driven and modular ETL scripts
- Performance considerations
- Interview-ready concepts

## Folder Structure
- `00_resources` – Optional references (not mandatory)
- `01_notes` – Concept explanations (basic → advanced)
- `02_practicals` – Hands-on Python scripts
- `03_projects` – Real-world mini ETL project
- `04_interview_questions` – Python interview questions for Data Engineers

## Outcome
After completing this module, you will be able to:
- Build Python-based ETL pipelines
- Handle real-world data issues
- Write production-ready Python scripts
- Confidently answer Python interview questions for Data Engineering roles
