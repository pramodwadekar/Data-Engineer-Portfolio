# 🚀 Data Engineering Portfolio

Welcome to my **Data Engineering Portfolio**.

This repository contains my complete Data Engineering learning journey and hands-on work, including:
- 📚 Notes (basic → advanced)
- 🧪 Practicals (hands-on practice)
- 🏗️ Real-world Projects (Data Engineering style)
- 🎯 Interview Questions (job-focused)

The goal of this repo is to build **industry-ready Data Engineering skills** and maintain a structured portfolio for interviews.

## 🧰 Tech Stack Covered
- **Python** (ETL, data handling, scripting)
- **SQL** (analytics + Data Warehouse + optimization)
- **PySpark** (big data transformations)
- **Databricks** (Delta Lake, pipelines, SQL + Spark)
- **Azure Data Factory (ADF)** (orchestration & pipelines)
- **Azure ADLS (Storage)** (cloud storage + partitioning)
- **Azure Synapse** (DWH + serverless SQL concepts)
- **Data Warehouse Concepts** (Star schema, SCD, OLTP vs OLAP)
