# Practical 06 — Default ACL + Inheritance (Most Important)

## Goal
Ensure new files automatically inherit permissions.

## Steps
1. Open folder `raw/orders/` → Manage ACL
2. Set both:
   - Access ACL
   - Default ACL

3. Create a new subfolder:
   - raw/orders/year=2025/
4. Check that permissions are inherited.

## Interview point
Default ACL avoids manual permission setting for every new file.
