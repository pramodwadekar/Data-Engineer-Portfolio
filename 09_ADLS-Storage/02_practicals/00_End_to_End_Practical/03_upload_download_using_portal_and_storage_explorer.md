# Practical 03 — Upload/Download using Portal + Azure Storage Explorer

## Goal
Learn basic file operations.

## Portal
1. Container → Upload
2. Upload a file: orders_2025_08_05.csv

## Azure Storage Explorer (recommended)
1. Install Azure Storage Explorer
2. Sign in
3. Browse containers
4. Upload folders and large datasets easily

## Interview point
Storage Explorer is commonly used by engineers for quick debugging.
