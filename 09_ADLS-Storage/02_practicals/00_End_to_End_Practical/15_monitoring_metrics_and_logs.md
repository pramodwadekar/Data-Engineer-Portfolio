# Practical 15 — Monitoring: Metrics + Diagnostic Logs

## Goal
Enable monitoring.

## Steps
1. Storage account → Monitoring → Metrics
2. Observe:
   - Transactions
   - Ingress/Egress
   - Latency

3. Diagnostic settings:
   - Send logs to Log Analytics
   - Enable StorageRead/Write/Delete

## Interview point
Monitoring is required for production troubleshooting.
