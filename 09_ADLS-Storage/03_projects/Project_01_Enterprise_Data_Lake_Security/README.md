# Project 01 — Enterprise Data Lake Setup + Security (RBAC + ACL)

## What is this project?
Create an enterprise-grade ADLS Gen2 lake with:
- Raw/Curated/Gold containers
- Correct RBAC role assignments
- Correct ACL (POSIX) permissions
- Default ACL inheritance
- Managed Identity access for Synapse/ADF

## Why this project?
RBAC vs ACL is the #1 ADLS interview topic and the #1 production failure reason.
