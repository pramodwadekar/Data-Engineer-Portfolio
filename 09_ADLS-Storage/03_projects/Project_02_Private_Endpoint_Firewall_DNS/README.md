# Project 02 — Secure ADLS with Private Endpoint + Firewall + DNS

## What is this project?
Secure ADLS Gen2 using:
- Storage firewall (disable public access)
- Private endpoint
- Private DNS zone configuration
- Validation from Synapse/ADF

## Why this project?
Private endpoints + DNS are mandatory in enterprises and common interview questions.
