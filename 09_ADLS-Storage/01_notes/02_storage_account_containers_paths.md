# 02 - Storage Account, Containers, Paths

## Storage account
Top-level resource.

## Container (filesystem)
Like a bucket.
Examples:
- raw
- bronze
- silver
- gold

## Folder path
Example:
`abfss://raw@<account>.dfs.core.windows.net/sales/2026/02/08/`

## Best practice naming
- separate zones by container or top folder
- avoid spaces
- keep consistent naming
