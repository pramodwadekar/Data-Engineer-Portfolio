# 03 — Containers, Folders, Files (Core Concepts)

Hierarchy:
Storage account → Container → Folder → Subfolder → Files

## Containers
Common containers:
- raw
- curated
- gold
- logs

## Folder partitioning (recommended)
Use:
- /year=2025/month=08/day=05/

## File naming
Good:
- orders_2025_08_05.parquet
Avoid:
- file1.csv
