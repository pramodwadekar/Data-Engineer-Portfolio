# 01 - ADLS Gen2 Introduction

## What is ADLS Gen2?
ADLS Gen2 is Azure Storage optimized for analytics:
- built on Blob Storage
- supports hierarchical namespace
- supports ACLs like Hadoop
- integrates with Spark, Synapse, ADF

## Why DE uses ADLS?
- cheap storage
- scalable
- supports Parquet/Delta
- supports data lake zones (bronze/silver/gold)
